fixtures/candidates_2026_parties.csv: VoteHub choice name -> party + general-election status
==============================================================================================

fixtures/ballot_2026_candidates.csv / fixtures/ballot_2026_seats.csv must stay under
CC BY-SA 4.0 if redistributed. Repository code remains MIT.

Columns: office, jurisdiction, name, party, status, source
  party  : DEM | REP | IND | LIB | GRN | OTH (OTH = any other minor party label)
  status : nominee        on the seat's general-election ballot as DEM/REP/IND
           minor          on the general-election ballot for a minor party
           not_on_ballot  appears in VoteHub polls / the previous map but is NOT listed on
                          the seat's general-election ballot (primary loser, withdrawn, or
                          hypothetical matchup). Party is the previous label, kept only
                          for audit; the v2 parser drops polls that include such a
                          candidate when require_nominees is on.
  source : wikipedia-2026-summary-table | prior-map

Primary source (2026-10-19 snapshot, fetched by the live configs' wikipedia_*_race_presence
sources and saved under data/snapshots/2026-10-19/):
  - https://en.wikipedia.org/wiki/2026_United_States_Senate_elections?action=raw
    sha256 e9ec0978e5f951c1604b6025dfa0dfb8c09d0804eba1723f4e58c81e1b6cc6e5
  - https://en.wikipedia.org/wiki/2026_United_States_House_of_Representatives_elections?action=raw
    sha256 488506a99eda2950d4544b89bd079dfc61252a70911dfbde7b1a946098fc9eaf
  The summary tables list each seat's general-election candidates with party labels and
  cite state election offices (e.g. Michigan Dept. of State 2026 November General Election
  Candidate Listing; Florida DOS Candidate Listing for 2026 General Election; Ohio SOS
  statewide candidate list; Nebraska SOS 2026 Elections; Maine SOS).

Rebuild:
  uv run python scripts/parse_wikipedia_2026_ballots.py \
      --senate-wikitext data/snapshots/<date>/wikipedia_2026_senate.wikitext \
      --house-wikitext  data/snapshots/<date>/wikipedia_2026_house.wikitext
  uv run python scripts/build_party_map.py --prior <previous candidates_2026_parties.csv>
